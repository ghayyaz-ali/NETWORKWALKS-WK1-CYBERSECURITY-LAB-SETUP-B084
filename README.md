📌 Project Overview

This project focuses on setting up an isolated virtual lab environment for cybersecurity practice, ethical hacking, and authorized penetration testing. The lab provides a controlled environment for performing security experiments without affecting the host system.

🛠️ Tools & Technologies

- Host OS: Windows / macOS
- Virtualization: VMware / VirtualBox / UTM
- Guest OS: Kali Linux
- Terminal: Linux CLI
- Package Management: APT

⚙️ Lab Setup Process

1. Virtual Machine Configuration

- Created a new virtual machine using a virtualization platform.
- Allocated appropriate RAM and storage resources.
- Configured network settings for a controlled lab environment.

2. Kali Linux Installation

- Downloaded the Kali Linux ISO image.
- Configured the VM to boot from the ISO.
- Completed the Kali Linux installation.

3. System Initialization & Updates

Executed the following commands to update the system:

sudo apt update

sudo apt full-upgrade -y

These commands update package information and install available system upgrades.

🎯 Key Learnings

- Understanding virtualization and VM configuration.
- Installing and configuring Kali Linux.
- Learning basic Linux terminal operations.
- Understanding virtual network configuration.
- Preparing a controlled environment for cybersecurity labs.
